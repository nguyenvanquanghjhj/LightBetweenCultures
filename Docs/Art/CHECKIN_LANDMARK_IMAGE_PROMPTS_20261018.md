# Check-in Landmark Image Prompts — 18 locations

**Purpose:** create future collectible landmark/postcard images.  
**Runtime source verified against:** `Assets/_Game/Resources/Content/GameplayContent.json`.  
**Important:** these are illustrated in-world postcard views, not documentary
photographs. Keep the fictional game setting and the existing 2D storybook
style.

## Global art brief

Create one clean 2D illustrated landmark postcard per prompt, portrait
composition, readable on a small mobile card. Warm hand-painted storybook
style, soft textured brushwork, clear silhouettes, gentle outlines, cinematic
light, culturally respectful fictional interpretation, no text and no logo.
Show the landmark as the main subject with a little surrounding context from
the corresponding map node. Do not copy a real photograph, do not add
unrelated landmarks, modern brand marks, tourists with detailed faces, UI,
camera frames, watermark, title, caption, or multiple versions in one image.

Recommended export: portrait 4:5 or 3:4, high resolution, background artwork
only. Keep the central landmark inside the safe crop so it remains clear in a
thumbnail.

## Consistency checklist before using an image

- The image must be recognizable from the node name and map context.
- The landmark must remain inside the mobile thumbnail safe area.
- Keep the setting fictionalized where the runtime description says “cách điệu”
  or “bản đồ giả tưởng”.
- Do not put fragment pieces, relic UI, quest text or camera UI inside the
  generated image.
- Do not use an image as a relic grant or fragment source until its check-in
  mapping and visual approval are separately recorded.
